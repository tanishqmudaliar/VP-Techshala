## [0.1.0] - 2026-07-14

### Added

- Demo login and signup flows backed by `localStorage`
- Seeded User/Admin demo accounts for quick presentation setup
- Event browsing, detailed event view, and participant registration for `ROBOWAR`
- Profile, contact, image gallery, and video gallery routes
- Desktop-first navigation with breadcrumbs and a collapsible sidebar drawer

### Changed

- Simplified the portal into a frontend-only demo experience with no backend dependency
- Organized auth and participant data into shared browser-storage helpers
- Standardized the app layout around route-based screens for the demo showcase
